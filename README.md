# BotForge

Discord bot for a Robux-based custom Discord bot shop.

## Railway variables

- DISCORD_TOKEN: Discord bot token
- OPENROUTER_API_KEY: OpenRouter API key
- OPENROUTER_MODEL: Optional OpenRouter model
- SHOP_NAME: Optional shop name
- STAFF_ROLE_NAME: Optional staff role name
- OWNER_ID: Optional Discord user ID for owner-only commands

Run with:
npm start

Then use /setup in the Discord server.
